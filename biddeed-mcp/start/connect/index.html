Setup guide

Connect BidDeed.AI in Claude — about 3 minutes.

BidDeed.AI runs as a Model Context Protocol (MCP) server. Add it as a custom connector in your Claude.ai settings and every foreclosure, tax-deed, and zoning tool becomes something you can just ask for — in whatever language you already think in.

Beta rollout note: the custom-connector endpoint is finishing production rollout on our side. If "Add custom connector" doesn't respond within a minute of connecting, wait a few minutes and retry — this page will drop the note the moment it's fully live. Don't have a key yet? Step by step

Add the connector

Works today on every Claude plan — Free, Pro, Team, Enterprise. No admin approval, no waiting on a directory review.

1

Open Claude.ai → Settings → Connectors

Click your profile in the bottom-left, then Settings → Connectors.

claude.ai/settings/connectors
ConnectorsManage
2

Click "Add custom connector"

Scroll to the bottom of the Connectors list — the custom-connector option is below the directory-listed apps.

3

Paste the BidDeed MCP URL

Name it BidDeed.AI and paste this exact URL into the connector URL field:

Add custom connector
https://biddeed.ai/api/mcp
Add
4

Sign in when prompted (OAuth)

Claude opens a sign-in window handled by our auth provider, WorkOS. Sign in with the same email you used for your trial, approve access, and you're bounced back to Claude — connected.

5

Turn the connector on in a chat

Start a new chat, click the + / tools menu, and toggle BidDeed.AI on. Claude now calls BidDeed tools directly when your question needs them.

If something's off

Troubleshooting

Claude says it can't reach the connector

The endpoint is in production rollout (see the note above). Retry in a few minutes. Still stuck? Email beta@biddeed.ai and we'll check it live.

The sign-in window doesn't return me to Claude

Make sure pop-ups aren't blocked for claude.ai, then retry step 4. This is a one-time sign-in per device.

I use Claude Desktop or Claude Code instead of claude.ai

Those support a local config file with your API key directly — see the full MCP reference for the stdio config.
